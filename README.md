# BrainQuest
Joko hezitzaile bat C + SDL2 erabiliz garatua. Programazioari, mekanografiari eta galdera-sistemari lotutako mini-jokoak ditu.

## Ezaugarriak
- Estatu-sistema (menua, munduak, mailak, irteera)
- Saguaren detekzioa (hover + click)
- Eskalada-animazioa (pose aldaketa)
- Mekanografia jokoa (letra ausaz + denbora-barra)
- Zaborra saihesteko jokoa (objektu erorketa + kolisioak)
- Galdera-sistema (TXT datu basea)

## Datu basea
Galderak fitxategi honetan daude:
- `img/galderak.txt`
